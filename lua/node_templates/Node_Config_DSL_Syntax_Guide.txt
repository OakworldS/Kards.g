节点配置 DSL 语法说明
Node Config DSL Syntax Guide
==========================================

Config DSL 是一种用于描述 INE 节点视觉组件布局和交互行为的文本语
言。每一条 config 字符串描述了一个节点在编辑器中的显示内容：文本
标签、下拉选择框、数字输入框、条件分支等。

Config DSL is a text language that describes the visual layout and
interactive behavior of INE node components. Each config string defines
what a node displays: text labels, dropdown selectors, number inputs,
conditional branches, etc.

一、组件类型 (Component Types)
========================================

1. 文本组件 (Text Component)
   - 语法: '文本内容'
   - 示例: '回合' '卡牌' '防御力'
   - 效果: 在节点中显示固定的文本标签

2. 下拉选择组件 (Select Component)
   - 语法: {选项1、选项2、选项3}
   - 语法: { @section_id }  (引用规则词汇表中的章节)
   - 示例: {等待、使} {攻击、防御、行动花费}  {@unit_types}
   - 效果: 显示下拉框供用户单选，选项用顿号（、）分隔
   - 特殊标记: 选项以 $ 开头和结尾（如 {$}、{$指定$}）时，
     标记为卡牌对象选择模式，点击会弹出卡牌选择器
   - @ 前缀: { @section_id } 表示不直接写选项，而是从规则词
     汇表（sh_rules_vocabulary.lua）中动态加载该章节的选项列
     表。section_id 对应词汇表中的章节 ID。
   - @ 变体: { @section_id ~ filter } 表示从该章节加载选项后，
     再按 filter 过滤。例如 { @effect_abilities ~ status } 
     仅保留状态类效果能力（过滤规则由词汇表定义）。

3. 数字输入组件 (Number Component)
   - 语法: [] 
   - 可选: [选项1、选项2] [lib] [lib+选项1、选项2]
   - 效果: 基本数字输入框，带加减按钮（0~99范围）
   - [选项1、选项2]: 数字槽模式，可在数字和选项列表间切换
   - [lib]: 接入变量库的所有数字变量
   - [lib+选项1、选项2]: 变量库 + 额外选项

4. 输出类型组件 (Output Type Component)
   - 语法: (n数字、p布尔值、t字符串、e卡牌对象)
   - 效果: 定义节点的数据输出端口类型和名称
   - 前缀: n=数字, p=布尔值, t=字符串, e=卡牌对象,
          g=数组, f=节点函数
   - config 末尾加 "2"（如 ...(t类型、e目标)2）启用
     双分支输出（满足/不满足两个执行输出点）

5. 输入类型前缀 (Input Type Prefix)
   - 语法: nptge 开头（可选）
   - 示例: n'当' e{指向一个}
   - 效果: 定义节点接收的输入数据类型端口
   - 前缀生命周期覆盖整个 config，后续所有组件共用该输入前缀

6. 函数槽组件 (Function Slot Component)
   - 语法: #
   - 效果: 显示编辑器内已定义函数变量的下拉选择列表
   - 选中函数后，节点的运行时行为由该函数的子图决定
   - 函数槽在序列化时存储函数变量名引用
   - 示例: {触发一次、保持触发} # '到' {$}
     表示在效果模式选择后，接着选择要触发的函数变量

二、条件分支 (Conditional Branches)
========================================
条件分支用于根据用户选择动态改变节点显示内容。

语法:
    if 条件1 then
        ...
    elseif 条件2 then
        ...
    end

- 条件只能是之前已定义的选择组件的某个选项
- 支持 if/elseif/else（else 使用 elseif true then）
- 分支内可以嵌套任意深度
- 分支内的组件只在对应选项被选中时显示

示例:
    {等待、使}
    if 等待 then
        [] '回合'
    elseif 使 then
        {回合结束、跳过回合}
    end

三、完整示例 (Full Examples)
========================================

1. 简单节点：
   '使' {$} '卡牌' {攻击、防御} {设置为、增加、减少} [] (n攻击力、n防御力)

2. 带条件分支：
   '回合'
   {等待、使}
   if 等待 then
       [] '回合'
   elseif 使 then
       {回合结束、跳过回合}
   end

3. 带输入前缀和多输出：
   n'当'
   {敌方、友方}
   {单位数量、总部血量} [] (n比较结果、p布尔值)

4. 带双分支输出：
   {条件} {是、否} (t类型、e目标)2

四、Base 结构描述 (Base Structure Description)
========================================

Base 是每个节点 JSON 文件中与 configs 并列的字段，用于描述节点
配置的纯结构骨架，供战斗系统机器解析使用。

Base 为单行字符串（非多语言对象），所有内容写在同一行。使用空格
替代换行符分隔 if/elseif/else/end 等关键字。

Base 的格式与原 config 相同，但遵循以下规则：

1. 文本组件（'文字'）— 完全忽略，不出现在 base 中
2. 选择组件 {选项列表} — 替换为 {选项总数, $所在项数}
   - 无 $ 标记：{N}，例如 {2}
   - 有 $ 标记：{N, M}，M 是 $ 所在项的序号（从 1 开始）
   - 示例：{$指定$、卡组顶、卡组底、随机} → {4,1}
   - 示例：{卡组顶、卡组底、随机、$指定$} → {4,4}
   - 示例：{$} → {1,1}
3. 数字组件 [] — 替换为：
   - 空槽 [] → [0]
   - 纯选项 [选项1、选项2] → [2]（填入选项总数）
   - 变量库 [lib] → 保持 [lib]
   - 变量库+选项 [lib+选项1、选项2] → [lib+N]（N 是附加选项数）
4. 条件分支 — 保留 if/elseif/else/end 结构
   - if 后的条件文字替换为上一个 {} 中被选项的序号
   - 示例：if 等待 then → if 1 then（等待是第一个选项）
   - 示例：elseif 使 then → elseif 2 then
   - 示例：if $指定$ then → if 1 then（$指定$ 是该 {} 的第 1 项）
   - elseif 1 or 2 then → 多个条件并列，表示选项 1 或 2
5. 输入类型前缀（e/n/t 等）— 保留
6. 输出类型（(e名称) 等）— 保留

举例：
  config: e{友方、敌方}{抽取、复制} 
          if 抽取 then
          [] '张' {$指定$、卡组顶、卡组底、随机}
          end
          (e影响的卡牌)

  base:   e{2}{2} if 1 then [0]{4,1} end (e影响的卡牌)

注意：base 是单行字符串，不包含空格和换行外的特殊格式。
if/elseif/else/end 用空格分隔，不使用换行缩进。

五、Varlib 变量索引 (Varlib Variable Indexing)
========================================

为了支持战斗系统通过固定序号访问变量库，变量库创建完成后建立
序数对照表：

1. KARDS.VarLib.IndexMap[tableID] = { [index] = varPath, ... }
2. 索引由 GetNumericVarPaths() 的排序结果决定，从 0 开始
3. 节点编辑器中变量库按此索引顺序排列展示
4. 节点保存变量时存储索引值而非路径字符串
5. 战斗系统运行时通过索引查找对应变量的当前值

索引示例：
  Index 0 → "Battle.Turn"
  Index 1 → "Battle.FriendlyHandCount"
  Index 2 → "Battle.EnemyHandCount"
  ...

六、数字槽 [lib+N] 的解析规则
========================================

当数字组件配置为 [lib+N]（N 个预设附加选项）时，数字槽的保存
值 S 按以下规则解析：

1. 变量库中的变量数量记为 L（通过 GetNumericVarPaths 获取）
2. 若 S < L：表示选中了变量库中的第 S 个变量
3. 若 S >= L：表示选中了第 (S - L) 个预设附加选项

其中"lib"在 UI 下拉中视为第 0 个选项，选中后打开变量库选择器。

七、注意事项 (Notes)
========================================
- 选择组件选项必须用顿号（、）分隔，不要用逗号或其他符号
- 条件分支的条件文字必须和选择组件中的选项文字完全一致
- 文本组件用单引号（'）包裹
- 数字输入用方括号（[]）表示
- 输出类型用圆括号（()）包裹
- 输入类型前缀放在 config 最前面（可选）
- 双分支输出标记 "2" 放在 config 末尾
- 所有括号和引号必须成对出现
- config 字符串中的换行会被忽略，仅用于提高可读性
- base 字符串应保持与 config 一致的换行结构（if/elseif/else/end 缩进）
